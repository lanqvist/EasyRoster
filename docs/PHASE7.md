# Фаза 7 — контекст для совета: альтернативы по слоту, ценность тир-сета, источник/грейд в BiS

Цель: во время разролла совет видит не только «+x% этому персонажу», а **насколько он этот предмет заменим** (есть ли эквивалент с других боссов/ключей), **кому тир-сет даёт больше всех**, и в BiS-листах сразу видно **откуда, с какой сложности и на каком треке** нужен предмет.

---

## 1. Альтернативы по слоту («заменимость» предмета)

### Что показываем
Для кандидата C и выпавшего предмета I (слот S):

| Поле | Смысл | Откуда |
|---|---|---|
| `v` | ценность I для C на треке дропа (уже есть: % сима / ранг BiS) | simc / BiS |
| `alt` | лучшая альтернатива в слоте S **из другого источника** (другой босс, M+, тайник, крафт) с её ценностью и источником | simc-кандидаты по слоту (у нас уже 167–180 предметов на персонажа) + BiS-кандидаты |
| `altM+` | лучшая альтернатива, которую можно **нафармить самому** (M+/крафт/тайник) | то же, фильтр по источнику |
| `gap = v − altM+` | «незаменимость»: насколько I лучше того, что C может добыть сам | вычисляется |
| `nAlt` | сколько предметов слота ≥ 95 % от v | вычисляется |

Пример на разролле тринкета «Гильотинная атака Зул'джина» (Myth):
- Мелда (маг): +2.9 %, лучшая альтернатива **+2.5 % Vile Vial (M+ Altar of Fangs)** → gap +0.4 % — заменим.
- Дащка (шп): +3.4 %, альтернатива +0.9 % (Voracious Heart, Ula'tek) → gap +2.5 % — **для неё это BiS без замены**.

Совет сортирует по `gap` (или по `v` — переключатель), т.е. отдаёт тем, кому иначе не закрыть слот.

### Реализация
- Движок: в `BisEntry` добавить `alternatives: { best, bestFarmable, count }` — считаем из тех же кандидатов слота (simc-мета уже содержит instanceId/encounterId → тип источника: raid-boss / mplus / trash / vault / catalyst). Для не-симящихся (хилы) — по рангу BiS-листа и трекам (альтернатива = следующий по списку из другого источника).
- Классификация источника предмета: `raid` (босс), `mplus` (instanceId в dungeonInstanceIds), `craft`, `catalyst`, `vault-only`. Уже есть `item_sources`.
- API/UI: в «Лут-ночь» и «Лут» у каждого претендента колонки **«Альт.» и «Gap»** (+ тултип с топ-3 альтернатив и источниками); в карточке персонажа BiS-лист уже перечисляет кандидатов слота — добавить бейдж источника (см. п.3).
- RCLootCouncil (db.lua, компактно): `ap` (% лучшей фармабельной альтернативы), `ai` (itemID альтернативы — имя аддон резолвит сам через `C_Item.GetItemInfo`), `as` (`m`/`r`/`c`/`v`), `ag` (gap). В колонке: `+2.9% · альт +2.5% M+`, цвет по gap (зелёный ≥2 %, серый ≤0.5 %). В тултипе: «Лучшая альтернатива: Vile Vial (Altar of Fangs, M+) +2.5 %; из рейда: … ». Опция сортировки колонки: по % / по gap.
- Пары слотов (кольца/тринкеты): альтернатива ищется относительно худшего из двух надетых (как в Droptimizer).

## 2. Тир-сет: кому он даёт больше

### Источник данных
1. **SimC (основной, персональный)**: для каждого ДД/танка два доп. профильсета в том же прогоне: `set_bonus=mid2_2pc=1` и `set_bonus=mid2_4pc=1` (принудительно включить, если нет) / `=0` (выключить, если есть) → **ценность 2pc и 4pc в его текущем гире**. Проверено: Morout — 4pc = +4.65 %. Стоимость: +2 профильсета к 170, ~0 времени.
2. Хилы: спек-таблица из гайдов Icy Veins/Wowhead (описание бонусов + оценка «сильный/средний/слабый») — вручную/парсинг текста, помечено «оценка». Bloodmallet `tier_set` для S2 пока не отдаёт данных.
3. Прогресс тира персонажа: сколько частей надето (по `itemSetId` из экипировки), какие слоты уже закрыты, что «катализируемо» (bonus 13662 в надетых предметах-источниках), что выиграно по истории RCLC (может лежать в сумке).

### Экран «Тир-сет» (новая страница)
Таблица статика с тепловой раскраской, сортировка по умолчанию — «ценность 4pc»:

```
Персонаж      Спека         Тир      2pc      4pc      До 4pc   Слоты нужны         Токены (босс)              Приоритет
Дащка         Shadow        3/5 ▮▮▮▯▯  +1.8%   +6.9%   1 часть  Плечи, Ноги         Idol (Sentinels), Relic…   ●●●●
Морout        Arms          2/5 ▮▮▯▯▯  +1.1%   +4.7%   2 части  Голова, Кисти, Ноги …                          ●●●
Мелда         Arcane        4/5 ▮▮▮▮▯  +0.9%   +3.2%   есть     —                                              ●
```
- «Приоритет» = ценность 4pc × (близость к 4pc: 1 часть до бонуса > 2 части) — формула настраиваемая, показывается формулой в тултипе.
- Клик по строке → какие именно предметы/токены с каких боссов закрывают слоты, и что даёт каждый (сим уже считает ценность каждого тир-предмета с учётом текущего количества частей).
- Блок «Токены»: для каждого токена S2 (по боссам) — список персонажей, которым он подходит, отсортированный по «прирост от этой части» (учитывая, что она даёт 2pc/4pc-скачок), с пометкой «закроет 4pc».
- В карточке персонажа: строка «Тир 3/5 · 2pc +1.8 % · 4pc +6.9 % · до 4pc: 1 часть (Плечи/Ноги)».
- RCLootCouncil: для тир-токенов и тир-предметов колонка показывает `тир 3→4/5 · закроет 4pc · +6.2%`; тултип — ценность 4pc для этого персонажа. Поля db.lua: `tp` (частей есть), `t4` (ценность 4pc %), `t2`, `tc` (закроет 2pc/4pc: 2/4/0).

## 3. Источник, сложность и трек в BiS-листе

Сейчас: название, ранг, источники (IV/WCL/сим) и «есть/нужно». Добавляем компактные чипы у каждого кандидата:

```
[🗡 Ula'tek · Mythic]  [Myth 318]  надето: Hero 4/6 (315)  → +3 ilvl / +4.8%
[🔑 Altar of Fangs · +10 / Тайник]  [Hero 305 · Myth 318 (тайник)]
[⚗ Coiled Altar + Катализатор]  [Myth 318]
[🔨 Крафт (Кузнечное)]  [Ветеран → Miф через Enchanted crest]
```
- **Источник**: тип (рейд/босс, M+ подземелье, тайник, катализатор, крафт, мировой босс) + название. Уже есть `drops`, `originalItemId`, instance type.
- **Сложность → трек → ilvl**: из BiS-источника (IV даёт bonus 13848 = Myth и т.п. — декодируем `decodeTrack`) и из таблицы «сложность → трек» сезона (Normal→Champion 292, Heroic→Hero 305, Mythic→Myth 318, M+ ключ→Hero, тайник→Myth). Показываем **на каком треке предмет является BiS** и **какой минимальный трек — уже апгрейд** над надетым (по симу: если Hero-вариант даёт +1.4 % — тоже зелёный, но слабее).
- **Надетое**: трек + ранг + ilvl (уже декодируется), Δ ilvl до BiS-варианта.
- Фильтр «показывать только рейд / только M+ / всё» и переключатель «сложность рейда: Heroic/Mythic» → у всех рейдовых кандидатов подставляется соответствующий трек и % (у нас есть pt по трекам).
- То же в «Лут» (у предмета — на каком треке он падает с этого босса при выбранной сложности) и в «Лут-ночь».
- В аддоне уже есть определение трека выпавшего предмета; добавить в тултип «BiS на треке Myth; на Hero — #2 в слоте».

## Вопросы для решения (штурм)

1. **Что считать «фармабельной» альтернативой**: только M+ (ключи) или также тайник (Myth-трек, но раз в неделю и случайно) и крафт? Предлагаю: M+ и крафт = фармабельно; тайник — отдельно (показывать, но не вычитать из gap).
2. **Приоритет тира**: формула `4pc% × k(близость)`; k = 1.0 если до 4pc одна часть, 0.6 если две, 0.3 если три+ ; тем, у кого 4pc уже есть — 0 (только апгрейд трека). Ок?
3. **Учитывать ли катализатор**: персонаж с 3/5 тира и катализируемым предметом в слоте по сути «4/5 через неделю». Предлагаю показывать «3/5 (+1 катализ.)» и в приоритете считать как 3.5.
4. **Сложность рейда по умолчанию** для чипов/треков — Heroic сейчас (прогресс), Mythic позже; переключатель в шапке страницы или настройка? Предлагаю настройку `season.raidDifficulty` + быстрый переключатель.
5. **Аддон**: показывать в колонке gap вместо/вместе с %? Предлагаю `+2.9% ▲2.5` (▲ = gap над фармабельной альтернативой), тултип — подробно.
