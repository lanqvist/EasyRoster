# Автосим лута (фаза 6) — разбор и решение

Вопрос: можно ли автоматически просимить весь лут, который может выпасть каждому персонажу статика, и во время распределения в RCLootCouncil показывать, сколько он даст DPS (ДД), выживаемости (танк) и пользы (хил) — без отдельного человека с Raidbots.

## Вердикт

| Роль | Автосим | Как |
|---|---|---|
| ДД | **да, полностью** | локальный SimulationCraft, profilesets по всему луту сезона |
| Танк | **да, с оговорками** | SimC даёт DPS / DTPS (входящий урон) / HPS (самолечение) — композит с весами; TMI как метрика профильсетов в текущей сборке недоступен |
| Хил | **SimC не умеет** | стат-веса (оценка) + тир-листы тринкетов; QE Live — приём ссылок на отчёты (как Droptimizer), позже — порт модели |

## Замеры (17.08.2026, ПК 16 потоков, simc nightly 1210.01)

- Импорт профиля из армори: `simc.exe armory=eu,tarren-mill,Morout save=…` — 5 с. Нам армори не нужно: экипировка с bonusID/камнями/энчантами и код талантов уже в базе → профиль генерируем сами.
- Arms-воин, 28 предметов The Venomous Abyss на Myth-треке (`bonus_id=12849/13657`), `target_error=0.5`, Patchwerk: **2,1 с**, ошибка 0,42% (320 итераций). Топ: `268213 main_hand +4.53%`, `268198 +4.01%`, `268214 +3.89%`, тринкет `270173 +3.26%` — тот же порядок, что Droptimizer.
- Blood DK: `role=tank tank_dummy=mythic profileset_metric=dps,dtps,hps` — работает, по каждому предмету три метрики. `tmi`/`theck_meloree_index` — «Invalid profileset metric».

Экстраполяция: рейд (30–40 предметов на спеку) × треки Hero/Myth + M+ (80–120 на Hero) + токены ≈ 200–300 профильсетов → 20–60 с/персонаж при 0,5 % (2–4 мин при 0,2 %). Статик из 26 человек — 10–30 мин, пересим только у кого сменилась экипировка.

## Архитектура

```
SimRunner (скачивание simc nightly → data/cache/simc, запуск, парсинг json2)
  ↑
SimService (очередь персонажей, статус, расписание после синка)
  ├─ profile.ts    — simc-профиль из БД: класс/спека/раса, talents=<loadout>, слоты id/bonus_id/gem_id/enchant_id
  ├─ candidates.ts — лут рейдов + M+ сезона, пригодный спеке (itemUsableBySpec), треки по сложности,
  │                  тир-токены → предмет тира класса; кольца/тринкеты — оба слота (берём max)
  └─ результаты → bis_candidates(source='simc'), meta{dpsBase, dpsMean, dtpsPct, hpsPct, track, tokenId}
        ↓
BisEngine (персональный сим поднимает предметы по %; уже реализовано для Droptimizer)
        ↓
карточка персонажа · Лут-ночь · db.lua (p=+x%) → колонка BiS в RCLootCouncil
```

Настройки (`config.sim`): включено, fight style (Patchwerk / HecticAddCleave), target_error, потоки, какие сложности рейда симить (Normal/Heroic/Mythic → Champion/Hero/Myth), M+ (Hero), автозапуск после синка, веса танка (dps/dtps/hps).

## Танки

Композит `score = w_dps·ΔDPS% − w_dtps·ΔDTPS% + w_hps·ΔHPS%` (по умолчанию 0.4/0.5/0.1), в UI и тултипе — все три раздельно. Правило: первичный порядок — трек/ilvl + BiS-лист, сим — тай-брейкер (танковый сим — грубая модель манекена, стамина/армор недооценены).

## Хилы

v1: стат-веса спеки × статы предмета (по ilvl) → относительный % к надетому, помечено «оценка». Тринкеты — тир-лист Icy Veins. QE Live-отчёты — приём ссылок (как Droptimizer). Позже — порт модели QE.

## Риски

- новые тринкеты/эффекты в SimC в первые дни сезона могут быть не реализованы → 0 % (помечаем);
- дефолтный APL vs реальная игра — стандартная погрешность, проценты сравнимы между кандидатами;
- снапшот экипировки Blizzard — на момент логаута; перед рейдом релог (или `gear1/gear2` из RCLC в игре).

## Портатив

`simc.exe` не кладём в zip (~120 МБ 7z): кнопка «Установить SimulationCraft» скачивает nightly в `data/cache/simc`; распаковка через `7zip-min` (встроенный 7za).
