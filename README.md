# EasyRoster

Локальный инструмент менеджмента ростера рейдового статика WoW (retail, Midnight): автосинк персонажей через Blizzard API, автоматические BiS-листы по каждому рейдеру, лут-таблицы сезона и подсказки «кому это апнет больше» прямо в окне голосования RCLootCouncil.

Исследование и план: [docs/PLAN.md](docs/PLAN.md).

## Возможности

| Область | Что делает |
|---|---|
| **Ростер** | Гильдия по Blizzard API → рейдеры по индексам рангов (задаются числами) → профили: спека, ilvl, экипировка (треки/bonusID, энчанты, камни), таланты, аватар. Автосинк по расписанию, `If-Modified-Since`. Имена рангов и заметки — из игры через аддон. |
| **Лут** | Справочники Raidbots (предметы, лут-таблицы рейда и M+ сезона, bonusID → трек/ilvl, катализатор). Автоопределение сезона. Русские имена через Blizzard item API. |
| **BiS** | Источники: Icy Veins (Overall / Raid / M+ / тир / тринкеты — все 40 спек), Warcraft Logs v2 (популярность у топ-парсов Mythic), Raidbots Droptimizer (по ссылке, персонально), ручные pin/exclude. Итог — взвешенная сумма; статус по экипировке и истории RCLC: есть / ниже трек / катализатор / нет. Тепловая карта статика, «кому нужен предмет». |
| **В игре** | Плагин `RCLootCouncil_EasyRoster`: колонка **BiS** в Voting Frame (Column API 3.23 + fallback), подсказка в окне ролла, рассылка данных совету по AceComm, экспорт ростера гильдии (ранги, заметки) в SavedVariables. Данные — `Data\db.lua`, генерируется приложением, применяется после `/reload`. |
| **Лут-ночь** | Босс → предмет → кто и насколько нуждается; история лута RCLootCouncil (импорт из SavedVariables). |

## Быстрый старт

Требуется Node.js ≥ 22.13 (используется встроенный `node:sqlite`).

```bash
npm install
```

```bash
npm run build && npm start
```

или на Windows — двойной клик по `start.cmd` (соберёт и откроет браузер).

Откройте http://localhost:4777 → мастер: ключи Blizzard → реалм/гильдия → ранги рейдеров (цифрами) → путь к `_retail_`.

### Рабочий процесс

1. **Ростер → «Обновить всё»** — гильдия и профили рейдеров.
2. **Лут** — справочники подтягиваются автоматически при первом запуске (Raidbots).
3. **BiS → «Обновить (ростер)»** для Icy Veins; для WCL нужны ключи (Настройки). Проверьте листы в карточке персонажа, при необходимости 📌/✕.
4. **Настройки → Интеграция с WoW**: «Установить аддон» → «Синк в игру (db.lua)» → в игре `/reload`. Дальше db.lua перезаписывается автоматически после каждого синка (можно отключить).
5. **Лут-ночь**: совет видит колонку BiS в RCLootCouncil; параллельно тот же расчёт — на странице «Лут-ночь». После рейда «Импорт истории лута» (или автоматически при следующем автосинке) — полученные предметы помечаются.
6. Рейдеры могут скинуть ссылку на Droptimizer — вставьте её в карточке персонажа (BiS-лист): персональные проценты поднимут предметы в его листе и появятся в игре.

### Разработка

```bash
npm run dev:server
```
```bash
npm run dev:web
```
Vite на 5173 проксирует `/api` на 4777. Тесты: `npm test` (парсеры Icy Veins/Lua/Droptimizer, движок BiS, интеграционный синк с mock Blizzard API).

```

```

## Ограничения и что дальше

- Blizzard API отдаёт профиль только после логаута персонажа; давно неактивные — «нет данных». Названия рангов/заметки — только через аддон (Настройки → «Импорт рангов/заметок» после `/reload`).
- В Midnight аддон-сообщения запрещены во время боссов — данные и голосование появляются после энкаунтера (RCLC это учитывает).
- WCL-популярность появится через 1–2 недели после старта сезона (когда накопятся Mythic-киллы); до этого работают Icy Veins и Droptimizer.
- Не реализовано (по плану — опционально): Wowhead через headless-браузер, локальный SimulationCraft (авто-«droptimizer»), упаковка в один exe.
